Exception Handling
==================

Exception handling is a way to handle runtime errors without stopping the
entire program unexpectedly.

1. What is an exception?
-------------------------
An exception is an error that occurs while a program is running. For example,
dividing a number by zero causes a ZeroDivisionError.

2. try, except, else, and finally
---------------------------------

try:
	result = 10 / 0
except ZeroDivisionError:
	print("A number cannot be divided by zero.")
else:
	print("Result:", result)
finally:
	print("This block always executes.")

How each block works:
- try contains code that may raise an exception.
- except handles a specific exception.
- else runs only when no exception occurs.
- finally runs whether an exception occurs or not.

3. Example with user input
---------------------------

try:
	number = int(input("Enter a number: "))
	result = 10 / number
except ValueError:
	print("Please enter a valid whole number.")
except ZeroDivisionError:
	print("A number cannot be divided by zero.")
else:
	print("Result:", result)
finally:
	print("Input process completed.")

In this example, try converts the input and performs the calculation. The
matching except block displays a helpful message when something goes wrong.

4. When and where to use exception handling
--------------------------------------------
Use exception handling when code may fail, such as when:
- Taking input from users
- Converting data types
- Reading or writing files
- Connecting to a database
- Calling an API or network service
- Performing calculations that may fail

5. Common built-in exceptions
------------------------------
- ValueError         : an invalid value, such as int("abc")
- TypeError          : an operation uses incompatible types
- IndexError         : a list index is outside the list's range
- ZeroDivisionError  : a number is divided by zero
- KeyError           : a dictionary key does not exist
- NameError          : a variable or function name is not defined
- FileNotFoundError  : a requested file does not exist
- AttributeError     : an object does not have the requested attribute
- ImportError        : an imported module or name cannot be imported
- ModuleNotFoundError: the requested module cannot be found
- PermissionError    : permission for an operation is denied
- OSError            : an operating-system operation fails
- AssertionError     : an assert condition is false

6. Raising an error yourself
-----------------------------
Use raise when a value is not valid. You can raise a built-in exception with
your own message:

try:
	age = -1
	if age < 0:
		raise ValueError("Age cannot be negative")
except ValueError as error:
	print("Error:", error)

7. Creating a custom exception
------------------------------
Create a custom exception by inheriting from Exception:

class InvalidAgeError(Exception):
	pass

try:
	age = -1
	if age < 0:
		raise InvalidAgeError("Age cannot be negative")
except InvalidAgeError as error:
	print("Error:", error)

Use a custom exception when an application needs a clear, meaningful error
name, such as InvalidAgeError or InsufficientBalanceError.

8. Practice examples
--------------------
The following examples intentionally cause errors. Run them one at a time,
preferably inside a try and except block.

# ValueError: the text cannot be converted to an integer.
number = int("abc")

# TypeError: a string and an integer cannot be added together.
result = "Age: " + 20

# IndexError: index 3 is outside this list's range.
items = ["pen", "book"]
print(items[3])

# KeyError: the key "email" is not in the dictionary.
student = {"name": "Asha"}
print(student["email"])

# NameError: the variable has not been defined.
print(username)

# FileNotFoundError: the file does not exist.
file = open("missing.txt")

# AttributeError: strings do not have an append method.
text = "hello"
text.append("!")

# ModuleNotFoundError: the module cannot be found.
import unknown_module

# AssertionError: the condition is false.
assert 2 + 2 == 5

9. Good practices
-----------------
- Catch specific exceptions instead of using a bare except.
- Keep the try block small.
- Use finally for cleanup, such as closing a resource.
- Use with open(...) for files when possible; it closes the file automatically.
